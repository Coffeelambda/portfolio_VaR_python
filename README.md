# Portfolio VaR in Python

A Python implementation of Value-at-Risk (VaR) models for financial portfolios.

The goal of this project is to implement and compare multiple market risk methodologies, starting from Historical and MonteCarlo metod VaR and progressively extending the framework with more advanced quantitative models.

## Planned Features

- Historical Value-at-Risk
- Parametric Value-at-Risk
- Monte Carlo Value-at-Risk
- Expected Shortfall (CVaR)
- ARIMA and VAR forecasting
- GARCH volatility models
- VaR Backtesting (Kupiec and Christoffersen tests)
- Portfolio analytics
- Risk visualisation
